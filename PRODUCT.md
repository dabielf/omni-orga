# Product

## Register

product

## Users

The primary user is one adult with AuDHD who feels overwhelmed or stuck and needs a small, clear set of tasks they can do now.

## Product purpose

Omni-orga stores goals and tasks without forcing the user to face their whole workload. It helps them choose tasks for Today and see what is available now.

## Brand personality

Calm, clear, respectful.

Things 3 is the main reference for quiet spacing, clear order, and one obvious next action. Omni-orga should not copy its layout.

## Anti-references

- Dense productivity dashboards.
- Scores, streaks, badges, confetti, praise, or blame.
- Surprise movement or changing content.
- Flavor text, motivational copy, repeated headings, or long explanations.
- Decoration that does not carry information.

## Design principles

- Show only what the current task needs.
- Make the next useful action clear.
- Use short, factual text. Remove any text that does not help the user decide or act.
- Keep state and navigation predictable.
- Make important changes reversible.

## Accessibility and inclusion

- Meet WCAG 2.2 AA.
- Support full keyboard use and clear focus states.
- Respect reduced-motion settings and avoid decorative motion.
- Never use color as the only signal.
- Keep choices few, controls familiar, and instructions close to where they apply.
- Test the main flows with autistic and ADHD adults.
